# Quantum Computing
1. A game that applies quantum mechanics using a quantum simulator. 
2. Run experiments using an actual quantum computer from IBM (requires an IBM Quantum API token).
3. A simulation of the one-dimensional particle-in-a-box model to calculate electron energy levels across 1–10 nm widths and visualize position probability densities
